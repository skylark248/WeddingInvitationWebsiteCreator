# Questions for the couple

Copy the message below into WhatsApp, or make a Google Form with the same questions. Paste their answers into Claude exactly as they send them. Claude copies names and dates **only** from these answers, so ask them to type carefully.

---

Hello! 🙏 To make your wedding website, please send these details, typed exactly as they should appear (spellings, "Late", initials and so on):

**1. Names**
• Bride's name, as it should appear
• Groom's name, as it should appear

**2. Family lines** (under each name)
e.g. "Grand D/o Late Mrs. … & Late Mr. …" / "D/o Mrs. … & Mr. …"
• Bride's side:
• Groom's side:

**3. Invitation wording** (optional; we can suggest some)

**4. Events.** For each one:
• Event name (Haldi, Mehendi, Sangeet, Wedding, Reception…)
• Date and start time
• Venue / place within the venue
• Dress code / attire (optional)
• A short line or tagline (optional; we can suggest some)

**5. Main venue**
• Venue name and city
• Google Maps link (open the venue in Google Maps → Share → Copy link)

**6. RSVP**
• Should guests reply on the website? (yes/no)
• Reply-by date
• Ask for: number of guests? phone number? which events? a message?

**7. Closing line**
• Family name to sign off with (e.g. "The Mehta & Rao Families")

**8. Music** (optional)
• A song or mantra you'd like playing (we'll need the audio file)

**9. Anything else** to include: hashtag, story, stay/travel info, contact person…

Thank you! ✨
