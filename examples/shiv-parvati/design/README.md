# Design files for this example (not in the public repo)

The designer's original PDF for this example isn't published: it contains a real client's details and the designer's artwork.

If you have it, copy it here as `frames.pdf` and run `npm run design -- shiv-parvati`. Everything in this folder except this README is git-ignored, so none of it can be pushed by mistake.

To see how the PDF import works without the real file, export any Figma design as PDF into this folder.
